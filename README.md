🛒 E-Commerce Web Application

A full-stack e-commerce web application built using the MERN stack with Firebase Authentication.
This project allows users to browse products, manage their cart, and place orders with a smooth and secure shopping experience.

🚀 Features

• User authentication using Firebase (Email & Password)

• Secure login & registration

• Product listing 

• Product details page

• Shopping cart functionality

• Checkout & order placement

• User account page with order history

• Protected routes for authenticated users

• Responsive UI for mobile and desktop devices

🧑‍💻 Tech Stack

Frontend

• React (Vite)

• Tailwind CSS

• React Router

• Axios

Backend

• Node.js

• Express.js

• MongoDB (Mongoose)

• Firebase Authentication

• Database

• MongoDB (Atlas)

📦 Core Modules

• Users

• Products

• Cart

• Orders

🔐 Security

• Firebase token-based authentication

• Protected API routes

• Secure backend validation

📱 Responsive Design

• Mobile-first responsive design

• Clean UI with modern gradients and layouts
